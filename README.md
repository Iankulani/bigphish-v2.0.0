## 🚀 Quick Installation

### Docker (Recommended)


# Clone repository

```bash
git clone https://github.com/Iankulani/bigphish-v2.0.0.git
cd bigphish-v2.0.0
```

# How to run

```bash
python bigphish.py
``` 

# Build and run
docker-compose up -d

# Access web interface
```bash
open http://localhost:8080
```
